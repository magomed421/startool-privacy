Startool — Политика конфиденциальности

Последнее обновление: 24 ноября 2026 года · Версия расширения: 0.36.0

Кратко. Startool обрабатывает данные страниц Starvell преимущественно локально в твоём браузере. Текст переписки передаётся Google только после отдельного согласия Firefox и только когда пользователь вручную запускает Gemini-корректор или переводчик.

1. Кто мы

Startool — независимое неофициальное расширение браузера для Starvell. Оно не связано с Starvell и не является продуктом Google. Разработчик Startool не управляет серверами Starvell или Google.

2. Какие данные обрабатываются локально

Для работы функций расширение читает элементы открытых страниц Starvell. В зависимости от используемых функций локально могут обрабатываться:

  • имена/ники собеседников, тексты сообщений и идентификаторы заказов в открытом диалоге — для переменных шаблонов, команд бота, закрепления и кнопок чата;
  • уведомления о покупках и элементы текущего заказа — для автоответчика;
  • видимые даты, статусы и суммы заказов — для локальной финансовой аналитики;
  • заметки CRM, быстрые фразы, шаблоны автоответов, команды и настройки, которые вводит сам пользователь.

Эти данные обрабатываются в контексте страницы и/или сохраняются в browser.storage.local Firefox. Startool не отправляет их на собственный сервер, не продаёт и не сдаёт в аренду.

3. Передача данных сторонним сервисам

Передача текста сторонним сервисам отключена до получения необязательного разрешения Firefox personalCommunications. Пользователь выдаёт его через встроенное окно Firefox, открыв значок Startool на панели браузера. Разрешение можно отозвать в настройках дополнения Firefox; после отзыва фоновые запросы блокируются.

Google Gemini API

Если пользователь нажимает кнопку ✨ «Исправить текст» и ранее разрешил передачу данных, расширение отправляет в Google Gemini API только текущий текст черновика из поля ввода вместе с инструкцией для корректуры. Полная история чата, профиль Starvell, CRM-заметки и история заказов в запрос не включаются. API-ключ пользователя передаётся Google в HTTP-заголовке x-goog-api-key для авторизации.

В бесплатном уровне Gemini API Google указывает, что отправленный контент может использоваться для улучшения продуктов Google. В платном уровне Google указывает, что контент не используется для улучшения продуктов. Условия и квоты могут изменяться; перед отправкой конфиденциальной информации проверь актуальные условия Google. Не отправляй пароли, платёжные данные и другие секреты.

Google Translate

Если пользователь вручную запускает перевод сообщения и разрешение Firefox выдано, расширение передаёт текст, выбранный для перевода, сервису Google Translate через HTTPS endpoint translate.googleapis.com. Полная история переписки не отправляется.

Google Fonts

Если пользователь использует настройки типографики, браузер может запросить таблицу стилей у fonts.googleapis.com и файлы шрифтов у fonts.gstatic.com. Эти запросы не содержат текст переписки, черновики или данные заказов, но Google может получать стандартные сетевые данные, например IP-адрес и технические заголовки HTTP.

Пользовательские фоновые изображения

Если пользователь указывает внешний HTTPS URL в настройке пользовательского фона, браузер загружает изображение с выбранного пользователем сервера. Этот сервер может получать стандартные сетевые данные запроса. Startool не выбирает такой адрес за пользователя.

4. Автоответчик, чат-бот и отправка сообщений в Starvell

Автоответчик и чат-бот могут отправлять настроенные пользователем ответы через интерфейс Starvell. Такие сообщения передаются Starvell и адресату чата как обычные сообщения пользователя. Они не отправляются на сервер разработчика Startool. Автоматические сообщения должны быть настроены и включены самим пользователем.

5. Локальное хранение и резервные копии

Настройки, команды, шаблоны, закреплённые чаты, CRM-заметки, данные аналитики и Gemini API-ключ хранятся в локальном хранилище расширения Firefox. Startool не шифрует API-ключ отдельным паролем. Экспорт резервной копии может включать ключ в незашифрованном JSON-файле; не делись такими файлами и удали их, когда они больше не нужны.

Пользователь может удалить локальные данные через управление данными расширения/удаление Startool в Firefox. Отдельно удали созданные JSON-резервные копии и другие экспортированные файлы.

6. Аналитика, реклама и продажа данных

Startool не содержит встроенной рекламной аналитики, трекеров использования, телеметрии или собственного сервера сбора статистики. Разработчик не продаёт и не передаёт данные пользователей третьим лицам. Сетевые обращения описаны выше и происходят только для включённых внешних функций.

7. Сторонние политики

  • Политика конфиденциальности Google.
  • Дополнительные условия Gemini API.
  • Уровни обслуживания и использование данных Gemini API.
  • Starvell — независимая платформа, на которой работает расширение.

8. Изменения и контакт

Политика может обновляться вместе с изменениями Startool или требований сторонних сервисов. Актуальная дата указана в начале документа.

Startool — Privacy Policy

Last updated: November 24, 2026 · Extension version: 0.36.0

Summary. Startool processes Starvell page data primarily inside the browser. Message text is sent to Google only after the user grants Firefox's built-in personalCommunications data permission and manually invokes Gemini correction or translation.

1. About Startool

Startool is an independent, unofficial browser extension for Starvell. It is not affiliated with Starvell or Google. The Startool developer does not operate Starvell's or Google's servers.

2. Data processed locally

Depending on the features used, Startool reads visible elements of Starvell pages and may process locally: chat participant names, message text and order identifiers; purchase notifications; visible order dates, statuses and amounts; and user-created CRM notes, quick phrases, reply templates, bot commands and settings.

This data is processed in the page context and/or stored in Firefox browser.storage.local. Startool does not send it to a Startool-operated server, sell it or rent it.

3. Data sent to third-party services

Text transmission is disabled until the user grants Firefox's optional personalCommunications data permission through Firefox's built-in consent prompt opened from the Startool toolbar button. The permission can be revoked in Firefox Add-ons settings. Background requests are blocked after revocation.

Google Gemini API

When the user clicks the ✨ correction button and has granted the permission, Startool sends only the current composer draft to the Google Gemini API together with a proofreading instruction. It does not send the full chat history, Starvell profile, CRM notes or order history. The user's API key is sent to Google in the x-goog-api-key HTTP header for authentication.

Google states that content submitted through the Gemini API Free Tier may be used to improve Google products. Google states that content submitted through the Paid Tier is not used for product improvement. Terms and quotas may change. Do not send passwords, payment details or other secrets.

Google Translate

When the user manually invokes translation and has granted the Firefox permission, Startool sends only the message text selected for translation to Google's HTTPS endpoint at translate.googleapis.com. The full conversation is not sent.

Google Fonts

When typography settings are used, the browser may request a stylesheet from fonts.googleapis.com and font files from fonts.gstatic.com. These requests do not contain chat text, drafts or order data, but Google may receive standard network information such as the IP address and HTTP technical headers.

User-provided background URLs

If the user enters an external HTTPS URL for a custom background, the browser loads the image from the selected host. That host may receive standard request metadata. Startool does not choose that URL for the user.

4. Auto-replies, chatbot and messages sent through Starvell

The auto-reply and chatbot features can send user-configured replies through Starvell's interface. Those messages are sent to Starvell and the chat recipient as ordinary user messages. They are not sent to a Startool-operated server. Automated messaging must be configured and enabled by the user.

5. Local storage and backups

Settings, commands, templates, pinned chats, CRM notes, analytics data and the Gemini API key are stored in Firefox extension-local storage. Startool does not separately encrypt the API key. An exported backup may include the key in an unencrypted JSON file. Do not share such backups and delete them when no longer needed.

Users can remove local extension data through Firefox's add-on data management or by uninstalling Startool. Separately delete JSON backups and other exported files.

6. Analytics, advertising and sale of data

Startool has no built-in advertising analytics, usage trackers, telemetry or developer-operated data collection server. The developer does not sell or share user data. Network requests are described above and are made only for enabled external features.
