## Enable GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the deployment to finish.
5. Open https://magomed421.github.io/startool-privacy/ and confirm both language sections and contact links work.
6. Paste the live URL into the Mozilla Add-ons privacy-policy field.

Only the privacy policy is hosted here. Do not upload extension source, API keys, backups, private chats, or user data. GitHub Pages content is public.
